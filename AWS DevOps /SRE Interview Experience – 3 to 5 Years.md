🚀 AWS DevOps / SRE Interview Experience – 3 to 5 Years

Recently, I attended interviews for AWS DevOps / Cloud Engineer / SRE roles and wanted to share some of the questions I encountered. These may help other DevOps professionals who are preparing for interviews.

🔹 Jenkins & CI/CD

• How do you design an end-to-end CI/CD pipeline?
• How do you store and manage credentials in Jenkins?
• How do you troubleshoot a failed Jenkins pipeline?
• What is the difference between Freestyle and Pipeline jobs?
• How do you implement approval before production deployment?
• How do you integrate SonarQube and Trivy into Jenkins?

🔹 Git & GitHub

• What is the difference between git merge and git rebase?
• How do you resolve merge conflicts?
• How do you protect sensitive information from being pushed to GitHub?
• How do you implement branching strategies in a project?

🔹 Docker

• What is the difference between an image and a container?
• How do you troubleshoot a container that keeps restarting?
• How do you optimize a Dockerfile?
• How do you push Docker images to Amazon ECR?

🔹 Kubernetes / EKS

• How do you troubleshoot CrashLoopBackOff and ImagePullBackOff?
• What happens when a Kubernetes worker node goes down?
• Difference between Deployment, StatefulSet and DaemonSet?
• What are readiness and liveness probes?
• How do you perform a zero-downtime deployment?
• How do you troubleshoot a pod that is stuck in the pending state?

🔹 AWS

• Explain VPC, subnet, route table and security groups.
• Difference between ALB, NLB and CloudFront?
• How do you secure an AWS environment?
• How do you troubleshoot an unreachable EC2 instance?
• How do you monitor applications using CloudWatch?
• How do you design a highly available application on AWS?

🔹 SRE / Troubleshooting

• What would you do if CPU utilization suddenly reaches 95–100%?
• How would you troubleshoot HTTP 503 errors?
• Application latency increased from 200 ms to 5 seconds—how would you investigate?
• Disk usage reached 95%—what steps would you take?
• How do you monitor application availability and latency?
• What are SLI, SLO and SLA?
• How do you handle a P1 production incident?

💡 My key takeaway:

For 3–5 years of experience, interviewers often focus not only on definitions but also on real-time troubleshooting, production scenarios, CI/CD implementation, AWS architecture, Kubernetes debugging and incident handling.
